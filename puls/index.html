Вопросы

Частые вопросы

Когда будет доступ?

Публичный запуск — 1 сентября. Участники списка ожидания получают приглашение на две недели раньше и цену запуска навсегда.

Безопасно ли подключать аккаунты?

Подключение идёт по официальным API площадок через OAuth. Мы не запрашиваем и не храним пароли, а доступ можно отозвать в один клик.

Что если площадка ограничит автопостинг?

Для площадок без публичного API публикация работает в режиме напоминания: пост готов, вам приходит уведомление и остаётся нажать «Опубликовать».

Можно перенести данные из таблиц?

Да. Импорт из Google Sheets и Excel: контент-план подтянется вместе с датами, текстами и вложениями.

Есть ли бесплатный период?

14 дней на любом тарифе, карта не нужна. После окончания данные сохраняются 90 дней.
